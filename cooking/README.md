# Cooking

A personal recipe collection, kept as plain Markdown.

## Layout

- `recipes/` — one Markdown file per recipe, named `kebab-case-title.md`

## Recipe format

```markdown
# Title

Servings: 4
Time: 30 min

## Ingredients

- ...

## Steps

1. ...
```

## Adding a recipe

Drop a new file in `recipes/` following the format above.
